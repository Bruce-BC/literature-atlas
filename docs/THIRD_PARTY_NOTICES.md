The web bundle uses the pinned packages in `package-lock.json`:

- D3 7.9.2 — ISC License, [upstream license](https://github.com/d3/d3/blob/v7.9.2/LICENSE).
- Cytoscape.js 3.35.0 — MIT License, [upstream license](https://github.com/cytoscape/cytoscape.js/blob/v3.35.0/LICENSE).
- esbuild 0.28.2 — MIT License, [upstream license](https://github.com/evanw/esbuild/blob/v0.28.2/LICENSE.md).

The palette source notices and pinned source commits are in `assets/palette-sources.json`; the last online verification is recorded in `docs/palette-source-verification.json`. The package includes the source notices under `THIRD_PARTY_NOTICES/palette-sources.json`; no upstream PDFs, private records, or model artifacts are bundled.
